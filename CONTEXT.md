# cliche

Слова, которыми о фреймворке говорят решения, комментарии и тесты.

**Приложение** (app):
CLI, который подключает cliche и даёт скриптам своё API.
_Avoid_: хост, клиент

**Скрипт команды** (command script):
Модуль на JavaScript с `exports.definition`, который становится командой приложения.
_Avoid_: плагин, расширение

**Объявление** (`exports.definition`):
Литерал скрипта: `short`, `long`, аргументы, флаги и ключи приложения. Читается без выполнения модуля.
_Avoid_: манифест

**Ключ приложения** (app key):
Ключ объявления, который регистрирует приложение: его содержимое проверяет и понимает приложение, а не cliche.
_Avoid_: плагин, метаданные

**Библиотечный модуль** (library module):
Модуль источника без объявления: общий код его скриптов.
_Avoid_: хелпер

**Источник** (source):
Каталог или `fs.FS`, путь файла в котором — путь команды.
_Avoid_: корень плагинов

**Корень** (root):
Источник, прочитанный каталогом: его команды и сломанные пути по первым словам.

**Каталог** (catalog):
Команды, сломанные пути и предупреждения всех корней после правила конфликтов.

**Модуль API** (API module):
Значение, которое приложение регистрирует под именем для `require`.
_Avoid_: SDK, рантайм

**Мост** (bridge):
Перевод значений и ошибок между Go и JS.

**Подмножество Node** (Node subset):
`fs`, `Buffer` и `fetch`: имена и ошибки Node, но синхронно и только перечисленное.
